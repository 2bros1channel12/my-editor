# Local reference trait profiles

Reference analysis is optional and accepts a user-selected local MP4 or MOV. The selected file is not imported into the project, copied, or retained. FFprobe reads stream metadata; FFmpeg samples one 160×90 grayscale frame per second for at most the first five minutes. The bounded sample and timestamp log live in an automatically deleted system temporary directory. The service does not log the reference path or media contents.

The analyzer estimates average shot length and a rate of cut-like visual changes. These are rough pacing cues: camera movement, screen changes, flashes, and fades can affect them, and they are not verified editorial cuts. The profile leaves caption density, punch-in frequency, music energy, humor, and narrative structure unknown for the user to set. It does not inspect identity, faces, voice characteristics, branding, logos, signature assets, or music content.

The UI holds the profile in memory and offers editing before saving. After explicit neutral-trait review, either Save brief or Save profile to a new brief revision persists the active neutral values with reference-derived analyzer provenance in the project database. Narrative structure is a fixed neutral category (`chronological`, `problem-solution`, `question-answer`, `step-by-step`, `demonstration-first`, `hook-explanation-summary`, `story-led-lesson`, `before-after`, or `unknown`); arbitrary creator-specific descriptions are not accepted. Older saved free-text values display as `unknown` in the editor without changing the stored brief until the user saves a new revision. The reference file path, frames, and source media are not stored. Selecting a saved brief reloads the saved trait values for review and editing. Changing projects clears any unsaved in-memory reference profile.

The process is bounded to 300 seconds of sampling and a two-minute FFmpeg timeout. Missing FFmpeg/FFprobe, inaccessible or unsupported files, and decode failures return actionable local errors. Current measurements use 1 fps grayscale frame differences; there is no subtitle OCR or classifier for punch-ins, music energy, humor, or narrative structure. The analyzer version is 2; version 2 replaces the previous free-text narrative field with the neutral category set.

Optional typed creator inspiration follows the separate [guided recipe review](GUIDED_BRIEFS.md) flow. A name alone does not establish editing traits: proposals use an explicitly selected generic recipe, make no claims about that creator, and exclude the separate inspiration field from saved project/planner data.
